# Project 1: Object Movement

A beginner Unity (C#) project demonstrating the basics of the Unity Editor: adding a GameObject (a cube) and giving it behaviour through a Component.

The component is a MonoBehaviour script ('PlayerMovement.cs') that moves the cube horizontally and vertically using keyboard inputs.

## Controls
- **W / A / S / D** or **Arrow keys**: move the cube.

## How to run
1. Clone the repository.
2. Open the project in Unity Hub (Unity version: *6000.6.8f1*).
3. Open the scene in the 'Assets' folder.
4. Press **Play**.

## Notes
The project uses Unity's 'Input.GetAxis', so **Active Input Handling** must be set to *Input Manager (Old)* or *Both* (Edit - Project Settings - Player).
